Messaging building blocks.

Explicit security configuration

createSecure() requires explicit origins. Handler permissions and payload limits are configurable; encryption is an optional plugin.

⚡

Fast

Synchronous local events and cross-context RPC, with reproducible benchmarks. Separate local callback throughput from transport and serialization costs.

🤖

Agent-Ready Design

llms.txt and integration guides describe application patterns. Schema validation supports a documented subset of JSON Schema.

📡

7 Transport Types

PostMessage, BroadcastChannel, SharedWorker, ServiceWorker, WebSocket, NativeBridge, MessageChannel.

🔌

Plugin Ecosystem

Retry, Circuit Breaker, Rate Limiter, Compression, Batching, Encryption. All tree-shakeable.

🏢

Observability utilities

Distributed tracing, Prometheus metrics, backpressure control, message versioning with migration.

Run the complete iframe example

Node.js 18+ and Git. This command starts both local origins and serves the HTML, modules and import maps.

git clone https://github.com/GiuseppeScottoLavina/crossbus.git
cd crossbus
node examples/quickstart/server.js

Open http://127.0.0.1:8780/. The widget at port 8781 displays {"id":123,"status":"ready"} after a real RPC. Both ports must be free. Stop with Ctrl+C.

What CrossBus provides

Signals, RPC, optional plugins and native WebView adapters.

Review the architecture, benchmark methodology and results, and native adapter sources. No independent security rating or universal performance ranking is claimed.

The unreleased 0.1.5 checkout adds bounded streaming and local native SDK packaging. Read the physical iPad/Pixel and browser qualification and the separate candidate performance comparison. Installing from npm currently selects 0.1.4.
