Draw in one tab, see it in every tab

Open this page in a second tab or window and place them side by side. Strokes and cursors travel between tabs as CrossBus signals over a BroadcastChannel, with no server involved.

    How it is wired

    Each tab binds the BroadcastChannel to one peer and only uses signals. A request would be ambiguous here: every other tab would receive it. The excerpt is loaded from the file this page runs.
