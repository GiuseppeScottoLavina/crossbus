        How it is wired

        Both endpoints share one key, provisioned by the application. Since 0.1.7 the plugin authenticates the message type, the handler name and the reply's request ID, and rejects plaintext. Since 0.1.8 each sender numbers its messages, so a copy is refused even when it arrives at the same moment as the original. Envelope metadata such as names and IDs stays visible on the wire.
