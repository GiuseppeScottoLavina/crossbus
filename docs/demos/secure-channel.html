        How it is wired

        Both endpoints share one key, provisioned by the application. Since 0.1.7 the plugin authenticates the message type, the handler name and the reply's request ID, rejects plaintext and remembers recent messages to refuse replays. Envelope metadata such as names and IDs stays visible on the wire.
